# S.T.A.L.K.E.R. 2 × АТБ

Репозиторій містить медіаасети з акції-колаборації мережі супермаркетів **АТБ** та розробників гри **S.T.A.L.K.E.R. 2: Серце Чорнобиля** (GSC Game World).

## Про акцію

У межах акції покупці АТБ отримували колекційні картки S.T.A.L.K.E.R. 2 при купівлі товарів на певну суму. Кожна картка містить QR-код, що веде на сторінку `s2-atb.com` з ексклюзивними аудіоматеріалами гри: архівними записами НДІЧАЗ (Науково-дослідного інституту Чорнобильської аномальної зони) та особистими щоденниками персонажів (матеріали КПК).

Колекція охоплює ключові події, персонажів, фракції, лабораторії та артефакти всесвіту S.T.A.L.K.E.R.

## Структура проекту

```
stalker2-cards-assets/
├── cards.json                  # Масив дескрипторів усіх 48 карток із метаданими та текстами
├── playlist.json               # Метадані треків (96 об'єктів)
├── images/                     # Обкладинки карток (48 × JPEG, 804×704 px)
├── audio-mp3/                  # Аудіозаписи у форматі MP3 (96 файлів)
├── audio-ogg/                  # Аудіозаписи у форматі OGG Vorbis (96 файлів)
├── tape-01-side-A.m3u          # Плейлісти для запису на аудіокасети 90 хв
├── tape-01-side-B.m3u
├── tape-02-side-A.m3u
├── tape-02-side-B.m3u
├── tape-03-side-A.m3u
├── tape-03-side-B.m3u
├── tape-listings.txt           # Переліки треків для касетних вставок
├── tape-covers/                # Варіанти обкладинок касет (68 × JPEG, 650×1000 px)
│   ├── tape-01-cover-variant-01.jpg … tape-01-cover-variant-27.jpg
│   ├── tape-02-cover-variant-01.jpg … tape-02-cover-variant-13.jpg
│   └── tape-03-cover-variant-01.jpg … tape-03-cover-variant-28.jpg

```

## Іменування файлів

- **Аудіо:** `XX.YY.mp3` / `XX.YY.ogg`, де `XX` — номер картки, `YY` — порядковий номер аудіозапису (01 = архів НДІЧАЗ, 02 = матеріали КПК)
- **Зображення:** `XX.jpeg` — обкладинка картки з номером `XX`
- **Плейлісти касет:** `tape-XX-side-Y.m3u` — касета `XX`, сторона `Y` (A або B)
- **Обкладинки касет:** `tape-covers/tape-XX-cover-variant-YY.jpg` — варіант `YY` обкладинки касети `XX` (650×1000 px)

## Плейлісти касет

Файли `.m3u` сформовано для запису колекції на аудіокасети формату C-90 (по 45 хв на сторону). Треки одного дескриптора не розділяються між сторонами.

Файл `tape-listings.txt` містить готові переліки треків для друку на касетних вставках. Нумерація треків наскрізна в межах касети: сторона A починається з `01` і продовжується на сторону B.

| Файл | Треків | Тривалість |
|---|---|---|
| `tape-01-side-A.m3u` | 20 | 43,6 хв |
| `tape-01-side-B.m3u` | 16 | 43,5 хв |
| `tape-02-side-A.m3u` | 16 | 39,5 хв |
| `tape-02-side-B.m3u` | 14 | 40,9 хв |
| `tape-03-side-A.m3u` | 22 | 44,0 хв |
| `tape-03-side-B.m3u` | 8 | 10,6 хв |

## MP3-метадані

Кожен MP3-файл містить повний набір ID3-тегів:

| Тег | Значення |
|---|---|
| Title | `<назва картки>. <назва аудіо>` |
| Artist / Album Artist | `S.T.A.L.K.E.R. 2` |
| Album | `Cards` |
| Track | Порядковий номер у плейлисті |
| Year | `2026` |
| Artwork | Обкладинка картки |
| Lyrics | Повний текст запису |
| Encoded by | `Andrii Frunt` |

## Обкладинки касет

Директорія `tape-covers/` містить 68 варіантів обкладинок у форматі JPEG (650×1000 px, співвідношення сторін 6,5:10):

| Касета | Варіантів | Файли |
|---|---|---|
| Tape 01 | 27 | `tape-01-cover-variant-01.jpg` … `tape-01-cover-variant-27.jpg` |
| Tape 02 | 13 | `tape-02-cover-variant-01.jpg` … `tape-02-cover-variant-13.jpg` |
| Tape 03 | 28 | `tape-03-cover-variant-01.jpg` … `tape-03-cover-variant-28.jpg` |

Зображення згенеровано у стилі наукової фантастики з урахуванням лору гри. Кожна касета має власну кольорову палітру:
- **Tape 01** — бурштиново-помаранчева (Скіф, Ріхтер, Випалювач мізків, С-Свідомість)
- **Tape 02** — синьо-фіолетова (Сидорович, Моноліт, вчений НДІЧАЗ, Зулус)
- **Tape 03** — радіоактивно-зелена (Дуга, Х-19, Альфа, Грозова Ягода)

Директорія `tape-covers-templates/` містить вихідні шаблони обкладинок у форматі Affinity Photo (`.afphoto`) та JPEG для ручного доопрацювання.
